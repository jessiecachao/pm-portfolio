医疗设备 UI 设计 交互流程

Nora 经皮耳迷走神经刺激（taVNS）治疗设备 — UI 与交互设计

产品设计 · 2026.06 – 2026.08 · 亿杉医疗

负责治疗设备从开机、耳夹检测、参数设置到治疗中优化建议的完整交互流程设计， 输出中英文双语高保真原型，覆盖 8 种设备状态与全部边界场景。

设计背景

taVNS 治疗设备需配合耳夹传感器实时监测生理信号，并根据信号质量动态调整刺激参数。 设备屏幕小、物理按键少，要求交互逻辑清晰、状态反馈明确，确保医护和患者都能快速理解当前状态。

核心设计

  • 梳理完整状态机：开机 → 耳夹检测 → 设备就绪 → 参数编辑 → 治疗中 → 暂停 / 优化建议 → 完成
  • 设计颜色编码体系：绿色=正常、红色=异常、黄色=警告、蓝色=治疗中
  • 完成中英文双语 UI 高保真设计与交互流程文档，迭代 3 版后进入开发

设计原型

设备就绪主界面 · 生理反馈实时监测 + 治疗参数设置
参数优化建议界面 · 当前方案 vs 建议方案对比确认
海外临床 Android APP 从0到1

Bilimonitor 新生儿黄疸监测 APP（尼泊尔）— 临床数据采集工具

移动端产品 · 2026.04 – 2026.08 · 亿杉医疗 · 已上线

针对尼泊尔临床数据依赖纸质记录、网络不稳定的问题，从 0 设计移动端数据采集 APP， 配合黄疸仪硬件实现蓝牙连接、离线采集、断网续传。

解决的问题

  • 当地医院网络环境差，需支持离线采集后批量同步
  • 医护人员录入负担重——纸质记录 60 项字段，容易出错且无法追溯
  • 需连接蓝牙黄疸仪硬件，读取实时测量数据并关联患者信息

核心方案

  • 协同临床医生梳理 60 项采集字段，按「患者信息 → 检测数据 → 血液验证」分组设计录入流程
  • 设计蓝牙连接流程：设备搜索 → 配对连接 → 状态实时显示，支持最多 3 台设备同时连接
  • 规划离线采集与断网续传链路：数据本地持久化，网络恢复后自动批量同步
  • 输出完整 PRD 和 Android 高保真原型，推动研发 3 周内完成首版上线
